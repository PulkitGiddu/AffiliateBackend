# Auth flow: UI → Backend → DB

## DB (from `sql script`)

Table **user_login**:

- `id` (UUID, PK)
- `email_id` (VARCHAR 255, UNIQUE, NOT NULL)
- `username` (VARCHAR 255, UNIQUE, NOT NULL)
- `first_name`, `last_name` (VARCHAR 255, nullable)
- `password_hash` (VARCHAR 255, NOT NULL)
- `is_active` (BOOLEAN, default true)
- `referral_code` (VARCHAR 50, UNIQUE, NOT NULL) — generated by backend
- `referred_by_id` (UUID, FK to user_login)
- `profile_picture_url`, `created_at`, `updated_at`

## 1. Register (sign up)

- **UI:** Collects email, username, first name, last name, password, optional referral code.
- **Request:** `POST /api/v1/users` (UserSignUpController). No JWT.
- **Body (UserDTO, snake_case):**  
  `email_id`, `username`, `password_hash` (plain password; backend hashes it),  
  optional: `first_name`, `last_name`, `referred_by_code`, `profile_picture_url`
- **Backend:** Validates → checks duplicate email/username → encodes password → generates `referral_code` → saves to `user_login` → returns 201 + UserDTO.
- **Security:** `POST /api/v1/users` is `permitAll()` in SecurityConfig.

## 2. Login (get JWT)

- **UI:** Collects email and password.
- **Request:** `POST /api/v1/auth/login` (AuthController). No JWT.
- **Body (AuthRequest, camelCase):** `email`, `password`
- **Backend:**  
  `AuthenticationManager.authenticate(email, password)` (loads user by email, checks password) →  
  generates JWT with email as subject →  
  returns 200 + `ApiResponse<AuthResponse>`: `{ success, message, data: { userId, email, token } }`
- **Security:** `/api/v1/auth/**` is `permitAll()`. JWT is not verified for this request.

## 3. After login (JWT used)

- **UI:** Saves `token` and `userId` (e.g. SharedPreferences). Sends `Authorization: Bearer <token>` on every API call.
- **Backend:** JwtAuthenticationFilter reads `Authorization` → validates token → extracts subject (email) → loads UserDetails → sets SecurityContext. Protected routes then run with authenticated user.

## Summary

| Step    | Endpoint              | JWT? | Who                    | Saves to DB?     |
|---------|------------------------|------|------------------------|------------------|
| Register| POST /api/v1/users     | No   | UserSignUpController   | Yes (user_login) |
| Login   | POST /api/v1/auth/login| No   | AuthController         | No (returns JWT) |
| Others  | e.g. /wishlist, /profile | Yes  | JWT verified first   | As per API       |
